PASOS EN LA TERMINAL DE VS CODE (dentro de la carpeta reservly2)

1) Copia encima los archivos de este zip, respetando las carpetas:
   README.md, LICENSE, .env.example, vercel.json, src/pages/admin/Admin.jsx

2) Quita los zips viejos y el vercel.json duplicado:
   git rm reservly-backup.zip reservly-src.zip src/vercel.json

3) Guarda y sube:
   git add .
   git commit -m "Preparar Reservly para portafolio: README, .env.example, licencia y widget embebible"
   git push

4) En Vercel → Settings → Environment Variables, añade:
   REACT_APP_ADMIN_EMAIL = tu email
   y vuelve a desplegar.

5) Si el repo es privado: GitHub → Settings → General → abajo del todo,
   "Change repository visibility" → Public.
